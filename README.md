# JavaScript Learning

A collection of small JavaScript examples covering language fundamentals. Each
example is a standalone script you can run and modify as you learn.

## Getting started

Install [Node.js](https://nodejs.org/), then run an example from the repository
root:

```sh
node 03_JS_Operators/07_Incre_Decre_Operators.js
```

Choose any `.js` file listed below to explore a different topic.

## Examples

### JavaScript basics - `01_JS_Basics/`

- `01_Helloworld.js` - print a first message to the console.
- `02_Math.js` - perform basic math operations.

### Identifiers - `02_JS_Identifiers/`

- `01_IND.js` - declare variables using `var`, `let`, and `const`.
- `02_IND_Rules.js` - rules for valid JavaScript identifiers.
- `03_IND_Rules2.js` - common identifier naming conventions.

### Literals - `03_JS_Literals/`

- `01_Literal.js` - string, number, boolean, `null`, and `undefined` literals.
- `02_Null_Undefined.js` - compare `null` and `undefined`.
- `03_Numbers.js` - integer, base-specific, and exponential number literals.
- `04_Number_Part1.js` - integer and floating-point literals.
- `05_Number_Part2.js` - numeric separators and `BigInt`.
- `06_Number_Part3.js` - special numeric values such as `Infinity` and `NaN`.

### Operators - `03_JS_Operators/`

- `01_Assignment_Operators.js` - assign and update variable values.
- `02_Arithmetic_Operators.js` - perform arithmetic calculations.
- `03_Comparision_Operators.js` - compare values.
- `04_Logical_Operators.js` - use logical AND (`&&`), OR (`||`), and NOT (`!`).
- `05_String_Operators.js` - concatenate strings and use template literals.
- `06_Ternary_Operators.js` - select a value with the conditional operator (`?:`).
- `07_Incre_Decre_Operators.js` - use prefix and postfix increment (`++`) and
  decrement (`--`).
- `08_Nullish_Operators.js` - use nullish coalescing (`??`) and compare it with
  logical OR (`||`).
