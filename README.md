# JavaScript Learning

A collection of small JavaScript examples covering the language fundamentals.

## Examples

### JavaScript Basics

- `01_JS_Basics/01_Helloworld.js` - a first JavaScript program.
- `01_JS_Basics/02_Math.js` - basic math operations.

### Identifiers

- `02_JS_Identifiers/01_IND.js` - examples of `var`, `let`, and `const`.
- `02_JS_Identifiers/02_IND_Rules.js` - rules for valid JavaScript identifiers.

### JavaScript Operators
- `03_JS_Operators/04_Logical_Operators.js` - examples of the logical AND (`&&`), OR (`||`), and NOT (`!`) operators.

## Run an example

Run a file with Node.js from the repository root:

```sh
node 03_JS_Operators/04_Logical_Operators.js
```
